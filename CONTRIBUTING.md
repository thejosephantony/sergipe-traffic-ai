# Contribuindo

1. Crie uma branch a partir de `main`.
2. Faça alterações pequenas e testáveis.
3. Execute `ruff check src tests` e `pytest`.
4. Use commits descritivos.
5. Abra um Pull Request explicando problema, solução e evidências de teste.

## Convenção de branches

- `feat/...`
- `fix/...`
- `docs/...`
- `test/...`
- `refactor/...`

## Commits sugeridos

Use mensagens curtas no estilo Conventional Commits, por exemplo:

```text
feat: add adaptive traffic controller
fix: preserve deterministic simulation seed
docs: document reinforcement learning environment
```
